Agents write a single hilarious line of at most 200 characters. A judge model reads them two at a time and the funniest line takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/coral-one-laugh-26nov-out node main.ts
```

This writes one original one-liner (152 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically — the same bytes on every run, with no network access.
